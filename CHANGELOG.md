# Изменения

## 2.7.0 · 21 ноября 2026

- Смена VPN сохраняет локальный порт. Новое подключение выбирает актуальный маршрут, а уже открытая TCP-сессия может продолжать работу по прежнему.
- Для VLESS и Hysteria 2 маршрут переключается через приватный Unix-сокет работающего Xray. Периодическая проверка его процесса заменена ожиданием завершения.
- Добавлены импорт Hysteria 2, подписанный каталог, автономные стартовые профили и смена адреса сайта.
- Обработка фрагментированных сообщений MTProto больше не копирует накопленные данные после каждого чтения. WebSocket-соединение использует два рабочих потока и системный TCP keepalive.
- В настройках виден маршрут через VPN. Обновление приложения и обновление профилей доступны отдельно.

## 2.6.8

Три стартовых профиля VLESS для Германии и Финляндии, режим «Стандарт», пользовательские подписки и установка обновлений патчами.
