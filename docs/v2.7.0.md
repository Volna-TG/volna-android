# Волна 2.7.0

Включите «Напрямую через VPN» и оставьте локальный прокси включённым в Telegram. При смене маршрута «Волна» сохраняет локальный порт. Подключения, для которых старая сеть исчезла, Telegram может открыть заново.

Вручную можно импортировать VLESS и Hysteria 2. Встроенные профили доступны без сайта и получают подписанные обновления. Настройки позволяют сменить адрес сайта и проверить каталог отдельно от версии приложения.

Установка: скачайте APK, откройте его на Android 8 или новее и подтвердите установку. Для обновления через приложение откройте **Настройки → Проверить обновления** после публикации патчей на вашем сайте.
