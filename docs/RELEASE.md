# Выпуск Android-сборки

Публичный код собирается без серверных паролей и без стартового каталога. По умолчанию доступны «Стандарт» и импорт. В официальный APK каталог добавляется на машине сборки.

## Стартовые профили и подписанный каталог

Файл `app/src/main/assets/profiles.json` исключён из Git. JSON содержит целочисленное поле `revision` от 1 и массив `profiles`. У каждой строки три поля: постоянный `id` (1–40 строчных латинских букв, цифр и дефисов), отображаемое `name` и рабочая URI-ссылка `link`. Используйте UTF-8. Стартовый каталог защищён подписью APK. Его содержимое публично для всех получателей APK.

Чтобы заменить каталог на сайте без пересборки, увеличьте ревизию и подпишите файл тем же ключом PKCS#12, которым подписан APK. Команда запускается на машине подписи с установленным Python-пакетом `cryptography`:

```sh
python3 scripts/sign-catalog.py app/src/main/assets/profiles.json /secure/signing.p12 profiles.json
```

На сайт загрузите **результат команды** в `/updates/profiles.json`. Запись должна быть атомарной (временный файл и rename). Приложение отвергает чужую подпись, повторную либо старую ревизию. Подписанная пустая коллекция с большей ревизией отзывает встроенные профили при следующей синхронизации. Доступ клиента к старой URI прекращается только после отзыва на соответствующем сервере.

## APK и патч

Соберите нативные библиотеки по README, выполните `./gradlew assembleRelease`, выровняйте APK инструментом zipalign и подпишите apksigner. Для обновления поверх прежней установки нужен прежний сертификат и больший versionCode. Сверьте сертификат командой `apksigner verify --print-certs`.

```sh
python3 scripts/volna-patch.py publish --version 2.7.0 --code 21 \
  --target volna-2.7.0.apk --base volna-2.6.8.apk \
  --key /secure/signing.p12 --out updates
```

Для каждой поддерживаемой базы добавьте ещё один `--base`. Скрипт проверяет восстановление APK перед выпуском манифеста. Подпись каталога и подпись обновления используют разные префиксы подписываемых данных. Разместите `release.json`, патчи и подписанный каталог в одном каталоге `/updates/`. Установка инициируется пользователем.

В GitHub Releases приложите подписанный APK и контрольную сумму к тегу `v2.7.0`. Текст объявления находится в [описании выпуска](v2.7.0.md).

## Проверка выпуска 2.7.0

Обе ABI собраны с NDK r27c. Чистый проект прошёл Gradle assembleDebug, официальный APK подписан прежним сертификатом. На Android 8 x86_64 установлено обновление поверх 2.6.8 и открыта главная страница. Подписи каталога и манифеста проверены, пять патчей от 2.6.4–2.6.8 восстановили APK побайтно.

На локальном Xray 26.10.31 проверены оба начальных маршрута и четырe переключения с продолжающейся передачей по открытому SOCKS-соединению. Это стенд с двумя TCP-серверами. Переключение настоящего VPN на телефоне, always-on с блокировкой, переход Wi-Fi ↔ LTE, переподключение Telegram и расход батареи требуют полевого прогона.

Сравнение парсера: 1 МиБ одним сообщением, входные блоки по 4 КиБ, HotSpot 17, три прогрева и медиана 11 повторов. Время 48,830 → 2,032 мс. Java-аллокации текущего потока 258,022 → 3,010 МиБ. Аллокации JNI и RSS не входят в эту метрику. У эмулятора во время замера памяти поверх приложения находился системный диалог ANR. Эти значения непригодны для вывода об экономии ОЗУ в Telegram.

Gitleaks 8.30.1 отметил закреплённую SHA-256 архива Xray в scripts/xray-android.gradle как возможный JFrog-токен. Эта строка используется для сверки файла, не для входа в сервис. Старый снимок исходников 2.6.8 также содержит эту контрольную сумму. Официальный каталог поставляется с APK отдельно от Git.
